# Cross-underlying robustness check

> **Superseded numbers.** Produced before the engine accounting fixes and the
> chain cleaning, on a single entry calendar. See
> [`ROBUSTNESS_REVIEW.md`](ROBUSTNESS_REVIEW.md) for current results and the
> status of each claim below.

Generated by [`cross_underlying.py`](../experiments/cross_underlying.py) — the article's exact
configuration (strike-based 40–45% OTM puts, DTE 90–180 entry / exit at DTE 30,
bi-monthly rebalance, daily exit checks, monetize-and-reinvest, externally-funded
annual budget) run on QQQ and IWM with runtime invariants armed, plus
window-matched SPY controls. Data: `data-v1` release, clamped to ≤ 2024-12-31.

## Results

| Underlying / window | Buy & hold | Best overlay excess | Max DD: hold → best overlay |
|---|---|---|---|
| **SPY 2008–2024** (published) | 10.65%, −51.9% | **+6.09pp** (3.3%/yr) | −51.9% → **−30.2%** |
| **IWM 2008–2024** | 6.55%, −54.9% | **+3.48pp** (3.3%/yr) | −54.9% → −55.4% (**no improvement**) |
| **QQQ 2011–2024** (chain starts 2011) | 18.53%, −35.1% | **−0.37pp** (best = least bad) | −35.1% → −36.3% (**no improvement**) |
| **SPY control, 2011–2024** | 13.64%, −33.7% | **−2.19pp** | −33.7% → −28.3% (improves) |

Full tables in the script output; all runs passed the engine's cash-flow and
valuation invariants.

## Interpretation

1. **The positive excess return is window-driven, not underlying-driven.**
   On the post-GFC window (2011–2024), the overlay is a *drag on SPY itself*
   (−2.2 to −2.5pp/yr at every budget). QQQ over the same window behaves the
   same way. The full-period outperformance in the published table is one
   mega-crash payoff (2008) amortized over 17 years; in the 14 years since,
   the strategy has steadily underperformed buy-and-hold.

2. **The GFC-payoff mechanism does replicate across underlyings.** IWM, whose
   chain covers 2008, shows the same direction as SPY (+1.0 to +3.5pp excess,
   monotone in budget). The excess is not a SPY-specific artifact — it is a
   "was there a crash deep enough to put 40–45% OTM puts in the money"
   artifact.

3. **The drawdown-protection story is the least robust part.** It replicates
   on SPY in both windows (−51.9→−30.2 full; −33.7→−28.3 post-GFC) but on
   neither QQQ (−35.1→−36.3) nor IWM (−54.9→−55.4). For QQQ the COVID
   decline (~−30%) never reached 40–45% OTM strikes, so the puts were pure
   drag exactly when protection was expected; IWM's trough timing similarly
   missed the puts' payoff windows.

4. **Implication for the article.** "Spitznagel is right" holds on
   SPY-2008-onward and directionally on IWM, but the honest generalization is
   conditional: *deep-OTM tail hedging pays for itself if and only if the
   window contains a crash deep enough to reach the strikes; otherwise it is
   a ~2–3pp/yr drag, and its drawdown protection depends on crash depth
   relative to strike distance, not on the hedge's existence.*

## Data caveats

- **QQQ options begin 2011-03-23** in the `data-v1` release — no GFC coverage,
  which is exactly why the SPY control over the same window matters.
- **IWM `underlying.parquet` ships `adjClose` entirely NaN** (upstream release
  gap). The script falls back to the unadjusted close: buy-and-hold CAGR is
  understated by the dividend yield (~1.3%/yr), but the overlay-vs-hold
  *excess* uses the same series on both sides and remains like-for-like.
- The options-data CDN fallback (`--allow-fallback`, "104 symbols") returns
  404 for every path including SPY as of 2026-06-11 — the upstream CDN is
  gone. The pinned GitHub Release is currently the only working options
  source, and it covers SPY, QQQ, IWM.
